# 会话与请求结果：行为完善需求

## 交付状态

本文定义已确认、需独立交付的目标行为，不是当前实现说明。[spec #1](https://github.com/natsusorahoshinochan-max/YesPlayMusic/issues/1) 交付会话与请求结果的代码结构重构，不包含本文的行为完善。当前模块、接口、请求失败结果和退出清理范围见[结构设计](../design/session-and-request-results.md)。

当前实现没有待验证状态、共享验证、完整登录尝试与会话结果隔离、并发失效去重、完整账号集合重置或请求合并。请求普通失败仍返回 `undefined`。现有二维码停止检查和网络故障不退出等局部行为，不代表本文全部要求已经实现；以下条目均按目标与验收要求阅读。

## 目标

完善 YesPlayMusic 在登录失败、离线恢复、并发请求和身份切换时的行为，明确会话状态、异步结果归属及请求失败契约。

代码职责与依赖整理见[代码结构重构需求](session-and-request-results-refactoring.md)。本文件定义会话行为改进的独立交付与验收要求。

## 身份模型

| 身份 | 含义与能力 |
| --- | --- |
| 访客 | 未建立网易云账号会话，也未选择公开音乐库浏览身份。 |
| 公开音乐库浏览身份 | 通过用户名选择网易云用户，仅浏览该用户可公开访问的音乐内容，不获得该账号的操作权限。 |
| 网易云账号会话 | 通过网易云认证建立的身份及授权关系。恢复的旧会话在验证前处于待验证状态。 |

本地用户资料用于展示，不作为授权证明。Last.fm 授权独立于网易云身份。

## 登录与登录尝试

- 认证成功即建立会话，资料和音乐库作为后续加载任务。
- 资料或音乐库加载失败时保留会话，提供重试，不要求重新认证，不沿用前一账号的数据。
- 登录尝试具有独立标识、可观察状态和取消能力。
- 二维码登录统一管理轮询、过期和结果归属，轮询请求不重叠。
- 页面展示登录状态；离开页面或切换登录方式时取消原登录尝试。
- 已取消或已被替代的登录尝试不能建立会话。密码登录同样遵守结果归属规则。

## 恢复与验证

- 启动时恢复已有身份和凭据，将恢复的账号会话标记为待验证。
- 离线时允许展示已有本地资料、使用缓存播放，网络故障不导致退出。
- 待验证身份执行账号操作前，等待一次共享的会话验证。
- 验证遇到网络错误时保留待验证状态，当前操作明确失败并允许用户手动重试。
- 写操作不因网络恢复而自动重放。

## 会话失效与退出

- 网络中断和请求超时不视为会话失效。
- 收到属于当前会话的明确失效信号时，统一清理账号状态并提示；并发信号只处理一次。
- 会话失效时保留当前公开页面；受保护页面转到登录页面。
- 主动退出立即清除网易云凭据、用户资料及账号音乐库状态。
- 退出和身份切换后，旧请求不能将数据写回，也不能使新会话失效。
- 保留设置、播放队列、缓存和当前播放；后续播放遵循当前身份权限。
- 网易云身份变化不解除 Last.fm 授权。

## 请求结果

- 请求成功返回业务数据，失败拒绝 Promise。
- 统一区分网络故障、服务端业务拒绝和明确的会话失效，提供稳定的错误类别及必要的原始错误信息。
- 请求失败明确传播，消除将失败吞成 `undefined` 的行为。
- 普通业务失败由发起操作的功能处理，会话失效交由会话模块处理。
- 所有受失败语义变化影响的调用者完成适配，包括加载状态收尾和错误处理。

## 异步结果与账号数据

每次会话和登录尝试具有独立归属。结果仅能影响所属会话或尝试；取消请求用于停止不必要的工作，归属检查保证结果正确性。

身份切换按以下顺序协调：

1. 阻止旧会话结果继续写入。
2. 重置明确登记的账号数据。
3. 允许新身份的数据写入。

会话相关资料和音乐库的加载具备以下行为：

- 合并相同会话下同类进行中的读取。
- 按依赖顺序加载，例如先确定喜欢的歌单，再获取歌曲详情。
- 每份数据分别记录加载与失败状态，支持单独重试。
- 用户主动刷新可以发起新读取。

清理账号状态时按数据归属保留用户偏好；持久化写回遵守相同规则，避免重新引入已清除的身份数据。

## 范围边界

行为完善覆盖会话、登录尝试、请求结果及统一账号数据加载。以下事项保持原有实现：

- 页面本地收藏状态在身份切换后的刷新方式。
- 跨账号听歌记录归属。
- 私人 FM 退出、切换和续播策略。
- 存储失败后的登录与降级方式。
- 历史版本兼容范围与损坏存档恢复能力。

## 验收要求

通过公开接口验证完整行为：

- 三种身份的权限与待验证状态符合身份模型。
- 网络错误和超时不触发退出。
- 并发会话失效只执行一次清理、提示和必要导航。
- 退出或切换后，旧请求和旧登录尝试的结果不能生效。
- 二维码轮询不重叠，离开页面或切换登录方式后原尝试停止生效。
- 认证成功、资料加载失败时保留会话并允许重试。
- 账号数据重置遵守数据保留要求。
- 待验证账号操作共享验证，失败后不自动重放写操作。
- 请求失败明确传播，调用者正确处理失败并结束加载状态。
- 同类进行中的读取按会话合并，各项数据可以单独重试。
- 存储样本恢复后，后续写回不会重新引入已清除的身份数据。
- Web 与 Electron 的登录、恢复、退出及受影响调用链符合上述行为。
