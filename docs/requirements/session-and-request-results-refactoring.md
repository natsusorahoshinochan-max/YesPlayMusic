# 会话与请求结果：代码结构重构

本文说明 [spec #1](https://github.com/natsusorahoshinochan-max/YesPlayMusic/issues/1) 已实现的职责边界与交付行为。具体接口和启动顺序见[结构设计](../design/session-and-request-results.md)。

## 目标与范围

会话规则、完整操作、账号数据及请求效果已集中到明确的模块，Vuex 是唯一响应式状态来源。页面、路由、Player、普通 JavaScript 工具和桌面调用者共用身份查询与账号数据操作；旧鉴权接口、转发层、重复编排和旧整对象写入路径已删除。

结构替换覆盖登录、恢复、公开音乐库浏览身份选择、退出、失效、每日凭据刷新、请求处理与账号数据加载。播放器、搜索、缓存和桌面生命周期保留各自归属，受影响的调用接口完成适配。

## 职责与交付行为

| 职责 | 实现 |
| --- | --- |
| 会话 | `session` Vuex module 集中身份查询与完整操作，通过注入使用凭据、认证、时间和应用效果；不直接依赖全局 store、router 或浏览器存储 |
| 账号数据 | `library` Vuex module 持有资料、喜欢歌单标识与各项集合，封装场景加载、刷新、收藏、歌单与云盘变更 |
| 用户偏好 | `preferences` module 持有设置与歌单筛选偏好，动态字段保持响应式和可持久化 |
| 请求 | Axios 请求实例集中传输和结果处理，通过必填失效回调连接会话；成功返回业务数据，普通失败保持 `undefined` 结果 |
| 应用协调 | 应用入口连接认证、导航、提示、请求环境与 Player；登录页保留表单及展示，完整操作管理凭据、身份、加载与导航 |
| 环境适配 | credentials 统一浏览器 cookie 与本地凭据备份；requestEnvironment 集中 Web/Electron 地址、凭据传输、realIP 和 proxy 差异 |

密码与二维码登录在凭据及身份更新后加载资料和音乐库预览，再导航。二维码轮询由 session 管理，页面切换模式或销毁时停止。公开音乐库浏览身份只加载公开内容，不获得账号写操作权限。

App 与音乐库页面使用不同场景入口，并共享内部加载实现。歌单、喜欢歌单标识和预览详情的依赖集中在 library；专辑等独立集合不阻塞预览就绪。收藏变更后的集合刷新和歌曲喜欢状态 IPC 通知由完整操作连接。

主动退出与会话失效共用本地清理逻辑，清除网易云凭据、模式、用户资料及喜欢歌单标识。主动退出不等待远端退出完成；失效不发起远端退出。两者保留各自导航目的。内存集合、设置、Player、缓存和 Last.fm 授权不因该清理重置。

## 持久化与初始化

内存状态按 session、library、preferences 分开，磁盘沿用 `data/settings` schema。一个持久化实现负责本地读取、默认值和支持的迁移、拆分初始数据与写回合并，保留未知字段与动态设置。账号集合保持非持久化，播放队列、播放进度、曲目缓存与 Last.fm 授权保持独立存储。

store 构造同步恢复本地数据并注册模块，不发请求或构造 Player。locale 与外观读取已恢复的设置；请求配置和失效处理在 Player 首次请求前完成；挂载时发起每日刷新并由 App 加载音乐库。路由和其他调用者读取同一身份查询，相关初始化循环依赖已切断。

## 兼容与验证

保留 Vue 2、Vuex、Axios，以及 Web、Electron 两种运行方式。访客、公开音乐库浏览身份和网易云账号会话保持各自功能含义；本地用户资料不单独证明账号权限，Last.fm 授权独立于网易云身份。

自动化验证通过公开接口使用真实模块与受控 adapter，覆盖登录、恢复、二维码生命周期、退出、失效、账号数据加载与变更、请求结果、Web/Electron 参数、持久化样本以及启动和桌面同步。自动化覆盖与手动环境验证的实际范围见[本地开发与验收环境](../development-environment.md)。

## 独立行为目标

[会话行为完善需求](session-behavior-improvements.md) 是另行交付的已确认目标，包括待验证会话、共享验证、完整登录尝试隔离、旧请求结果屏蔽、并发失效去重、完整账号数据重置、请求合并和失败契约重设计。spec #1 不实现这些行为，也不将现有实现中的缺口解释为新业务规划。
