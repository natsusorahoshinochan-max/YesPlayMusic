# 三个复杂度收束原型

仅在 `codex/prototype-remaining-complexity` 分支中运行。

在项目根目录运行 `yarn prototype:complexity`，打开
http://127.0.0.1:8093/album/1754736 。按 Ctrl+C 结束本地服务。
右下角「一次性原型」面板读取实际播放器和页面状态；收起面板后操作页面。
修改原型代码后刷新页面。

| 原型问题 | 手动操作 | 观察位置 |
| --- | --- | --- |
| 当前歌曲是否需要额外 ID 镜像？ | 播放歌曲、切歌、打开歌词、刷新页面 | 歌曲高亮、歌词标题、面板曲目与镜像字段是否存在 |
| UNM 空值是否可以只在原生边界解释？ | 设置页填写/清空备选音源、修改搜索模式与 FLAC，点击面板的查询按钮 | 实际 native search 参数及返回资源；此按钮直接调用原生 adapter |
| 原生弹窗能否承接模态交互并删除全局滚动开关？ | 打开专辑/艺人/歌单简介；滚轮、Tab、Shift+Tab、PageDown、Esc；右键菜单后滚动和点击外部导航 | 主页面位置、内容位置、焦点是否在弹窗内、菜单可见性 |

长内容验证使用艺人简介，并将浏览器窗口缩小到内容需要滚动的高度。
通过原型面板的「艺人」链接进入页面，打开简介后使用浏览器后退、前进，检查缓存页面恢复。
专辑和歌单用相同操作检查页面销毁重建。
添加歌曲、新建歌单之间的弹窗交接需要真实账号；在歌词显示时也检查打开和关闭。
Electron 的键盘与滚动行为需要在桌面应用中单独操作。

UNM 查询使用当前歌曲 ID 重新读取网易云真实详情，调用已安装的原生库。
观察入口的两个 Cookie 固定为空，查询不使用登录凭据。端口为 3000、3093、8093。
浏览器设置保存于独立的 8093 origin；原生调用记录位于启动时打印的
`ypm-PROTOTYPE-wipe-me-*` 临时目录。

旧配置迁移的独立入口：`node src/store/unm-settings.prototype.cjs`。
它运行历史版本的真实清空设置操作生成存档，再交给当前恢复与保存入口；
输出文件位于打印的 `/tmp/ypm-PROTOTYPE-wipe-me-unm-*` 目录。

三项候选分别保存在独立提交中。观察工具、运行记录和截图另行提交。
原始观测文件位于仓库根目录 `prototype-evidence/`。
